From data to discovery

One workflow, end to end.

Each stage leaves a trace that can be inspected, rerun and compared.

01 / IMPORT

Bring data in

EEG, ROI/BOLD and generic neural time-series enter a consistent project structure.

02 / QC

Find issues early

Signal quality and preprocessing decisions are visible before downstream modeling.

03 / REVIEW

Explore features

Inspect traces, spectra and derived features before fitting a model.

04 / MODEL

Fit computational models

Run supported model classes or research-specific extensions in a controlled environment.

05 / COMPARE

Compare runs

Keep subjects, variants, parameters and outputs side-by-side instead of scattered across folders.

06 / REPORT

Export evidence

Generate reports and provenance bundles that preserve the path from input to result.
