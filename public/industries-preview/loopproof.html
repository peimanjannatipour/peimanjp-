Observe → Model → Test → Explain

From physical reality to trusted insight.

The page follows the same diagnostic loop as the concept itself.

01 / OBSERVE

Map the physical loop

Reservoirs, pumps, valves, branches, sensors and grow zones remain visible as a system topology.

02 / STREAMS

Read selected signals

Flow, pressure, pH, EC, temperature and state variables provide the observation layer.

03 / MODEL

Estimate expected behavior

A compact digital twin represents how the loop should respond under known conditions.

04 / TEST

Run a bounded check

Predefined diagnostic sequences narrow the plausible cause without replacing the PLC.

05 / COMPARE

Expected vs observed

The system compares the measured response with the model under the same bounded condition.

06 / EXPLAIN

Return evidence

The operator gets a plausible cause, supporting evidence, confidence and a recommended inspection step.
